The easiest way to install Radarr on macOS is to use the App archive with the steps described below.

{{#> alert heading="Radarr migration"}}

The Radarr package will attempt to automatically migrate an existing Radarr database. Radarr v0.2 used the user's home directory ~/.config/Radarr to store the application data which v4 also uses.

{{/alert}}

  1. Download App package

    {{icon "download"}} macOS App (Apple Silicon) {{icon "download"}} macOS App (Intel)

  2. Install App

    Open the archive and drag the Radarr icon to your Applications folder.

    {{#> alert warning=true}}Radarr v5 is not compatible with macOS versions older than 10.15 (Catalina) due to .NET incompatibilities.{{/alert}}

  3. Self-sign Radarr

    Open Terminal and run:

    codesign --force --deep -s - /Applications/Radarr.app && xattr -rd com.apple.quarantine /Applications/Radarr.app

  4. Start Radarr

    Open Radarr.app in your Applications folder.
