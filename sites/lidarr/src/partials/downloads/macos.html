The easiest way to install Lidarr on macOS is to use the App archive with the steps described below.

{{#> alert heading="Lidarr v0.8 migration"}}

The Lidarr v1 package will attempt to automatically migrate an existing Lidarr v0.8 database. Lidarr used the user's home directory ~/.config/Lidarr to store the application data which v1 also uses.

{{/alert}}

  1. Download App package

    {{icon "download"}} macOS App (Apple Silicon) {{icon "download"}} macOS App (Intel)

  2. Install App

    Open the archive and drag the Lidarr icon to your Applications folder.

    {{#> alert warning=true}}Lidarr v1 is not compatible with macOS versions older than 10.13 (High Sierra) due to .NET incompatibilities.{{/alert}}

  3. Start Lidarr

    Open Lidarr.app in your Applications folder.
